# 3.1 Conceptual Framework

## Core Concept
StegoLock is a secure document management system that utilizes **steganography** and **encryption** to protect files by fragmenting, hiding, and distributing them across cloud storage using carrier files.

---

## Key Conceptual Pillars

### 1. Security Through Steganography
* **Fragmentation**: Documents are split into multiple UUID-tagged fragments
* **Carrier Files**: Encrypted fragments are hidden within diverse media carriers (Text, Audio, Image)
* **Distributed Storage**: Stego-files are distributed to Backblaze B2 cloud storage
* **Structural Mapping**: `FragmentMap` records fragment relationships and order
* **Storage Mapping**: `StegoMap` records cloud storage locations for each fragment

### 2. Multi-Layer Encryption Pipeline
* **AES-256-GCM Encryption**: Files are encrypted before steganographic processing
* **Key Derivation Functions (KDF)**: Passwords are processed through KDF before hashing
* **SHA-256 Validation**: Fragments are validated during reassembly
* **UUID Tagging**: Each fragment receives a unique identifier for tracking

### 3. Dual Pipeline Architecture

#### 3.1 Locking Pipeline (Secure Storage)
* **Input**: User uploads original document
* **Process Flow**:
  - Encrypt file using `CryptoService`
  - Select diverse carrier files from pool
  - Segment file into fragments with structural mapping
  - Embed fragments into carrier files via Python scripts
  - Push stego-files to Backblaze B2 cloud
* **Output**: Protected document with distributed stego-fragments

#### 3.2 Unlocking Pipeline (Secure Retrieval)
* **Input**: User requests document unlock
* **Process Flow**:
  - Retrieve stego-files from B2 based on `StegoMap`
  - Extract shards from carriers using `batch_processor.py`
  - Validate fragments via SHA-256 checksums
  - Reassemble fragments into encrypted blob
  - Decrypt blob to restore original file
* **Output**: Original document available for download

### 4. Role-Based Access Control (RBAC)
* **Standard User**: Upload, lock, unlock, and manage personal documents
* **User Admin**: Manage user accounts and storage quotas
* **System Admin**: System-wide maintenance and infrastructure monitoring
* **Superadmin**: Full system control and administrative oversight
* **Middleware Protection**: Roles attached to sessions via Laravel Middleware

### 5. Workspace Organization
* **Hierarchical Folders**: Users create parent-child folder relationships
* **Real-Time Storage Tracking**: `refreshStorageUsed()` calculates usage dynamically
* **Dynamic UI Feedback**: Color-coded storage progress bar (Cyan ≤90%, Red >90%)
* **Document Metadata**: File type, size, timestamp displayed via `DocumentCard`

### 6. Collaboration Without Exposure
* **Relational Sharing**: Shares create access links without file duplication
* **Acceptance Workflow**: Recipients must accept shares before access
* **Shared Indicators**: "Users" icon badge on shared `DocumentCard`
* **Notification System**: Red badge for pending share invitations

### 7. Administrative Oversight
* **User Management**: Promote/demote users, manage quotas
* **Infrastructure Monitoring**: "Zombie Detection" for orphaned cloud files
* **Cover Auditing**: `ScanCoversJob` ensures stego-pool health and capacity
* **System Control Panel**: Specialized admin section with 3-column metrics grid

### 8. Cinematic User Experience
* **Processing Visualization**: Cyan shimmer effect during locking
* **Reassembly Animation**: "Imploding Puzzle" effect during unlocking
* **Status Translation**: Technical states mapped to user-friendly labels
  - `mapped` → "Embedding fragments..."
  - `embedded` → "Protecting..."
  - `stored` → "Locked"
* **Real-Time Polling**: Instant status feedback without client-side timers

### 9. Technical Architecture Stack
* **Backend**: Laravel (PHP) with Inertia.js for SPA-like experience
* **Frontend**: React.js with Tailwind CSS ("Midnight Void" theme: `#0b1224`)
* **Steganography Engine**: Python scripts (`batch_processor.py`, `embedding/`)
* **Cloud Storage**: Backblaze B2 integration via `B2Service`
* **Queue System**: Laravel Jobs (`ProcessSteganoJob`, `ProcessUnlockJob`)
* **Database**: MySQL/PostgreSQL with Eloquent ORM

---

## Design Philosophy
StegoLock operates on the principle that **security through obscurity** (steganography) combined with **strong encryption** and **distributed storage** provides superior protection compared to traditional single-file encryption or cloud-only storage solutions.
